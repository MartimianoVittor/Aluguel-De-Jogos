## 📖 Sobre o Projeto

O Aluguel de jogos é um sistema de estudo que permite controlar o aluguel entre três jogos fazendo a verificação se um dos jogos já está alugado e se sim não permite que o usuário alugue outro até ter devolvido o anterior.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos e componentes da página.
- **CSS3:** Estilização e organização visual da interface.
- **JavaScript:** Implementação da lógica do jogo, geração de números aleatórios e interação com o usuário.

## 🎯 Objetivos de Aprendizado

Durante o desenvolvimento, foram trabalhados conceitos como:

- Lógica de programação.
- Declaração e manipulação de variáveis.
- Estruturas condicionais.
- Funções e eventos.
- Geração de números aleatórios.
- Manipulação do DOM (Document Object Model).
- Interação entre HTML, CSS e JavaScript.

## 🎮 Funcionalidades

- Controle de estado.
- Alteração visual com base na lógica dem JS.
- Sistema de confirmação de escolha.
- Exibição dos resultados diretamente na interface.
- Validação das informações fornecidas pelo usuário.
